# Decision Ledger

Store material product/governance decisions here.

Suggested file naming:

```text
D-0001-short-slug.md
```

Template:

```markdown
# D-0001 — Decision title

Date: YYYY-MM-DD
Status: proposed | accepted | superseded | rejected
Risk: low | medium | high | critical

## Trigger / evidence
- source links / issue ids / experiment ids

## Analyst interpretation
- observed problem
- evidence quality
- source/cohort bias

## Counter-evidence / alternatives
- strongest case against changing
- alternative explanations

## Decision
IGNORE | OBSERVE | EXPERIMENT | ACT | SPECIALIST_REVIEW

## Change / experiment
- smallest reversible action

## Explicitly not changing
- guard against accidental scope expansion

## Verification
- success/failure criteria
- review date or next evidence window
```

Keep these records concise and factual. Do not store private chain-of-thought.
